# Advanced Bruteforce Login Tool

A multi-threaded login bruteforce tool with session resumption and detailed logging.

## Features

- Multi-threaded for faster password attempts
- Session resumption capability
- Detailed logging (both console and file)
- JSON log format for easy parsing
- Customizable form fields and success indicators
- Colorful console output
- Progress saving and restoration

## Requirements

- Python 3.6+
- Required packages (see requirements.txt)
